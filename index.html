01What is bruster?

An OS-native browser engine

bruster wraps WKWebView (macOS), WebKitGTK (Linux) and WebView2 (Windows) through wry. No bundled Chromium, no Node runtime, nothing to download — just one small native process.

A JSON-lines API

Drive it from any language: write one JSON object per line to stdin, read results and event objects from stdout. Navigating, finding, clicking, filling, screenshots — everything is a method call.

Model Context Protocol

Run with --mcp and every method becomes a tool for Claude, Codex, opencode and other MCP clients, including screenshots as image content and page events as notifications.

One process, one profile

Multiple tabs share cookies and storage. Persistent profiles and HTTP cache make repeat visits noticeably faster. Cleans up after itself; no stray sessions.

02Why it's fast

No Chromium baggage

Uses the engine the OS already ships. One ~1 MB process instead of a hundred megabytes of downloaded runtime. The first tab warms about:blank while the agent sets up.

Cached repeats

Persistent HTTP cache and profiles mean repeat visits load about 2× faster. --no-images can cut page loads by ~30% on content-heavy sites.

Software-only rendering mode

Under a virtual display (Linux headless), rendering goes software-only, halving memory use.

Measured, not claimed

The numbers above come from scripts/bench.py, run on every push in GitHub Actions: build, cold start to {"event":"ready"}, local page load, snapshot round-trip and idle RSS.

03Install

  1. One-liner for macOS, Linux and Windows prebuilds (dropped into ~/.local/bin):
    curl -fsSL https://raw.githubusercontent.com/aliilyas/bruster/main/install.sh | sh
  2. Linux needs WebKitGTK 4.1 and, without a desktop session, Xvfb — the script warns you if either is missing. From source: cargo build --release.
  3. Artifacts for every platform are attached to the releases page.

04Use it from an agent (MCP)

opencode, Claude Desktop, Cursor, Windsurf and Zed share one shape:

{ "mcpServers": { "bruster": { "command": "bruster", "args": ["--mcp", "--quiet"] } } }
claude mcp add bruster -- bruster --mcp --quiet      # Claude Code
codex mcp add bruster -- bruster --mcp --quiet       # Codex CLI
{ "servers": { "bruster": { "type": "stdio", "command": "bruster", "args": ["--mcp", "--quiet"] } } }   # VS Code

Windows keep hidden under --mcp; add --visible to watch the browser while the agent works.

05Flags

--mcpspeak MCP on stdio instead of the native protocol; implies --hidden
--hidden/--visiblepark windows off-screen / show them
--quietsilence GL/ALSA/GTK noise on stderr
--viewport WxHinitial window size (default 1280x800)
--user-agent UAoverride the user agent
--profile DIRpersistent cookies and storage
--proxy URLhttp://host:port or socks5://host:port
--init-script FILEJS injected into every page before its own scripts
--insecureignore TLS errors (Linux)
--no-imagesskip image loads, ~30% faster pages (Linux)
