A Bruster test is a plain-text file. It is a short set of instructions that you save, edit, and run. In this lesson, you will create one and make sure its name is correct.

Use the bruster-practice folder from the previous lesson. It should already contain the Bruster program. Keeping the program and test together makes the first commands easier to follow.

Start with the provided file

Download first-check.bru ↓

Save this file inside bruster-practice. If it appears in Downloads first, move it into the practice folder. Some browsers open unfamiliar files as text instead of downloading them; in that case, use Save As or copy the example below into a plain-text editor.

The part after the final dot is the file extension. Here it is .bru. That tells you this is a Bruster test file. The whole name should be first-check.bru.

{{first_check}}

Do not worry about understanding every line yet. In ordinary language, this file says: open the practice website and check its browser-tab title. We will explain the commands after your first run.

Choose a plain-text editor

On Windows, Notepad is enough. On a Mac, TextEdit can work, but choose Format → Make Plain Text before saving. On Linux, use the normal text editor for your desktop. An editor such as Visual Studio Code also works if you already have one.

A word-processing document is different. Word and similar applications can add formatting information that does not belong in a test file. Use plain text rather than a rich-text or document format.

Keep the straight double quotation marks shown in the example: ". Curly quotation marks such as “ and ” may look similar, but they are not valid quotes in the test language.

Check the saved filename

A common first mistake is accidentally creating first-check.bru.txt. The file may look right when your computer hides known extensions.

  • Windows: in File Explorer, turn on File name extensions under View. If saving from Notepad, choose All files in the Save as type field and use first-check.bru as the name.
  • macOS: check the name in Finder’s Get Info panel. Confirm that TextEdit has not added .txt. Save as plain text with UTF-8 encoding if asked.
  • Linux: check the full name in your file manager. Most text editors keep the extension you type.

If your browser added a number because you downloaded the file twice, you may see first-check (1).bru. You can rename it to the simpler name once you know which copy you want to keep.

Know which copy you are editing

Open the file from your practice folder. Edit that copy, and save it with Ctrl+S on Windows/Linux or Command+S on Mac. Bruster reads the saved file on disk, not the unsaved text still sitting in your editor.

You can also download all eight practice files as a ZIP. Extract them into your practice folder when you want the later examples. The ZIP contains text files, not a Bruster executable.

Try it: inspect your folder

Find these two items in the same folder: bruster or bruster.exe, and first-check.bru. Open the test file and compare its contents with the example above. Save and close it once.

Before you move on

You know where your file is, you can see its full name, and it contains plain text. Those small checks prevent many confusing first-run errors.
