Good questions

Before you start.

Is bruster a replacement for Playwright?

It is an alternative for workflows that benefit from a native-webview controller and JSON-lines or MCP access. Playwright offers a complete testing ecosystem, cross-browser engines, tracing, and browser-context isolation. Compare the trade-offs for your workload.

Does bruster need Node.js or a browser download?

The bruster executable needs no Node.js. It uses WKWebView on macOS, WebKitGTK on Linux, and WebView2 on Windows. Install the native runtime where required; rendering also uses its libraries and helper processes. WebView2 is Chromium-based.

Can I run it in CI without a display?

On Linux, WebKitGTK needs a display even in hidden mode. Install Xvfb for a virtual display. When DISPLAY is unset, bruster automatically tries xvfb-run. See the CI setup.

Can I use bruster from Python?

Yes. Start the executable with Python’s standard-library subprocess module, write a JSON request to stdin, and read stdout until you receive its matching ID. Try the complete Python example.
